# Gucci Goblin

## Назначение темы уведомлений о КВ

В окружении приложения задай `TELEGRAM_ADMIN_USER_IDS` — числовые Telegram ID
пользователей, которым разрешено менять тему, через запятую:

```dotenv
TELEGRAM_ADMIN_USER_IDS=123456789,9876543210
```

ID разбираются один раз при создании `TelegramAccessService` и сохраняются
в неизменяемом `Set<Long>`. Пробелы вокруг ID и дубликаты допускаются.
Доступ проверяется по `message.from.id`; наличие и значение username не влияют
на проверку. Команды без отправителя или от пользователей вне списка отклоняются.

`TELEGRAM_ADMIN_CHAT_ID` используется для отправки сообщений об ошибках.
`TELEGRAM_GROUP_CHAT_ID` задаёт группу клана.
При запуске через Docker Compose переменные передаются из `.env`
или окружения запуска.

После перезапуска приложения открой нужную тему в группе клана и отправь
`/war_thread@имя_бота` без аргументов с аккаунта из списка администраторов.
Бот сохранит ID группы и текущей темы в `telegram_chat_settings`
и отправит подтверждение в эту же тему.

Повторная команда в другой теме этой группы заменяет выбранную тему.
Настройка применяется к новым и ещё не отправленным уведомлениям;
уже отправленные сообщения повторно не отправляются.
Пока тема не назначена командой, используется `TELEGRAM_WAR_THREAD_ID`.
