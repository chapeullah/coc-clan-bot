# Gucci Goblin

## Назначение темы уведомлений о КВ

В окружении приложения задай `TELEGRAM_ADMIN_USER_ID` — числовой ID пользователя,
которому разрешено менять тему. `TELEGRAM_ADMIN_CHAT_ID` по-прежнему задаёт чат
для сообщений об ошибках, а `TELEGRAM_GROUP_CHAT_ID` — группу клана.
При запуске через Docker Compose новая переменная передаётся из `.env`
или окружения запуска.

После перезапуска приложения открой нужную тему в группе клана и отправь
`/war_thread@имя_бота` без аргументов со своего аккаунта.
Бот сохранит ID группы и текущей темы в `telegram_chat_settings`
и отправит подтверждение в эту же тему.

Повторная команда в другой теме этой группы заменяет выбранную тему.
Настройка применяется к новым и ещё не отправленным уведомлениям;
уже отправленные сообщения повторно не отправляются.
Пока тема не назначена командой, используется `TELEGRAM_WAR_THREAD_ID`.
